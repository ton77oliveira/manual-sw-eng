# AGENTS.md

Leia `memory/PROJECT_CONTEXT.md` antes de implementar. Este projeto é Markdown-first e a aplicação deve permanecer simples, self-hosted e sem dependências desnecessárias.

- Não inclua segredos, dados de clientes ou URLs privadas em arquivos versionados.
- Prefira tarefas pequenas, diffs revisáveis e testes antes de commits.
- Conhecimento global fica em `knowledge/`; contexto privado em `projects/`.
- Commands educacionais são read-only e não devem alterar código.
- Specs seguem `specs/NNN-slug/{spec.md,plan.md,tasks.md}`.
